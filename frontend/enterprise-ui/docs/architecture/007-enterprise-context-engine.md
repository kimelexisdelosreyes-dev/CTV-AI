# Enterprise Context Engine

The Context Engine owns normalized, deterministic snapshots of the current enterprise situation. It accepts explicit runtime context and provider contributions, merges equivalent entity IDs, preserves source attribution, assigns confidence from explicit evidence and provider agreement, and expands relationships one level only.

Providers never depend on the Context Engine. Search may consume normalized project context as a ranking signal, but remains provider-neutral. The engine does not use AI, generate prompts, traverse a graph recursively, or persist organizational memory.
