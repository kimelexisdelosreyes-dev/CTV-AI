# CTV ONE Enterprise Experience Platform — RC1 Release Notes

## Release scope

RC1 packages the completed Phase 6.0 capability platform and Enterprise Experience workspace. The release includes the feature-gated authenticated navigation entry, capability catalog, safe operational metadata, structured text result rendering, accessible loading/status/error states, and responsive layouts.

Frontend typecheck, lint, 115 tests, and production build pass. Focused capability API, governance, and manifest validation passes (8 tests); the complete backend regression suite passes (701 tests). The migration chain resolves to revision `0011`.
