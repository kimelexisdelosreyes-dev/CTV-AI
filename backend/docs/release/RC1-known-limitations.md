# RC1 Known Limitations

- Capabilities remain default-off pending controlled activation.
- This package contains no live provider, browser performance, or authenticated environment measurements; those are pre-activation operational checks.
- The capability API intentionally exposes only safe public summary and structured result fields; provider, prompt, handler, routing, and stack details are not presented.
- No uploads, streaming, cloud providers, persistence additions, or new capabilities are included.
- RC1 does not begin Phase 7.0 work.
