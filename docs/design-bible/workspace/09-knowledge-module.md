# 09 - Knowledge Module

## Purpose

Knowledge should feel alive. Workspace should show knowledge that helps today's work, not a static library.

## Groups

- Recommended.
- Recently Viewed.
- Trending.
- Required Reading.
- Project Related.
- Templates.

## Discovery Rules

Rank recommendations by:

1. Current project context.
2. Required reading.
3. Role and department relevance.
4. Recently updated official sources.
5. Saved or frequently used documents.
6. Trending within allowed scope.

## Visual Hierarchy

- Required Reading outranks recommended content.
- Project Related outranks general trending content.
- Recently Viewed is useful but should not dominate.
- Templates should appear when the user is likely creating work.

## Card Anatomy

- Title.
- Knowledge Space.
- Status: approved, updated, required, unverified.
- Why recommended.
- Last updated.
- Action: read, save, use in AI Studio.

## Permission

- Never show inaccessible knowledge titles, filenames, snippets, owners, or metadata.
- Sensitive spaces appear only when the user can discover them.
- Required Reading must identify policy source and due date.
