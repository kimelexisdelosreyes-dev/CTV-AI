# 07 - Quick Actions

## Purpose

Quick Actions make common role-based work reachable without turning Workspace into a command wall.

## Limits

- Desktop: 5 visible actions maximum.
- Tablet: 4 visible actions maximum.
- Mobile: 4 visible actions maximum in a two-column grid or horizontal row.
- Overflow goes to "More actions".

## Role Recommendations

| Role | Recommended Quick Actions |
| --- | --- |
| Editor | Generate subtitles, Enhance image, Open transcript, Upload media, Review AI jobs |
| Writer | Write script, Search Knowledge, Summarize source, Translate, Submit draft |
| Executive Producer | Review approvals, Open active productions, Assign next action, Summarize project, Export report |
| Marketing | Build presentation, Generate proposal, Search brand assets, Open campaign, Share draft |
| Graphic Artist | Build presentation, Generate image, Open brand kit, Upload design asset, Request approval |
| Multimedia Artist | Generate media, Enhance image, Compare versions, Open assets, Export deliverable |
| Sales | Generate proposal, Search approved messaging, Open opportunity, Build presentation, Export PDF |
| HR | Search policy, Draft response, Open employee request, Submit approval, Publish knowledge |

## Customization

- Default actions come from role and permissions.
- Future personalization may allow reorder, pin, and hide.
- Custom actions must remain permission-aware.
- Disabled actions need a plain-language reason.

## Interaction

- Click executes or opens configuration.
- Keyboard focus moves through actions in visual order.
- Overflow menu preserves recently used actions.
