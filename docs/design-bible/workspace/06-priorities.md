# 06 - Today's Priorities

## Purpose

Today's Priorities is a priority engine. It is not a task dump.

## Categories

- Approvals.
- Deadlines.
- Meetings.
- Blocked work.
- Required reading.
- Pending AI review.
- Security or account attention.

## Sorting

Sort by:

1. Time sensitivity.
2. Business impact.
3. Dependency impact on other people.
4. User ownership.
5. Recency.

## Grouping

- "Needs approval"
- "Due today"
- "Waiting on you"
- "Review AI output"
- "Required reading"

## Visual Treatment

- Priority cards are compact.
- Use clear status chips and due time.
- Use icons as secondary signals, not decoration.
- High priority should be visually distinct without alarm-heavy styling.

## Priority Card Anatomy

```text
+------------------------------------------+
| Approval required                  Today |
| Fire Documentary script review            |
| Blocks: Editor handoff                    |
| [Review]                                  |
+------------------------------------------+
```

## Empty State

Quiet day copy should be useful:

"No urgent priorities. Continue a project, review recommended knowledge, or start an AI Studio capability."
