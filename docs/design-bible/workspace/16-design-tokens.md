# 16 - Design Tokens

Design tokens are documented here only. Do not treat this as CSS.

## Typography Scale

| Token | Size | Use |
| --- | --- | --- |
| Display | 40-48 px | Rare Workspace hero emphasis |
| Page Title | 32-40 px | Workspace title or greeting |
| Section Title | 20-24 px | Module headers |
| Card Title | 16-18 px | Cards |
| Body | 14-15 px | Default text |
| Metadata | 12-13 px | Time, status, source |
| Label | 12 px | Form and chip labels |

## Spacing Scale

| Token | Value | Use |
| --- | --- | --- |
| 1 | 4 px | Micro gaps |
| 2 | 8 px | Icon gaps |
| 3 | 12 px | Dense card internals |
| 4 | 16 px | Standard card internals |
| 5 | 20 px | Module gaps |
| 6 | 24 px | Section rhythm |
| 8 | 32 px | Desktop page rhythm |
| 10 | 40 px | Hero padding |
| 12 | 48 px | Large desktop margins |

## Radius

- Controls: 8 px.
- Workspace cards: 10-12 px.
- Hero panel: 14-16 px.
- Pills and chips: full radius.

## Elevation

- Level 0: page background.
- Level 1: standard card.
- Level 2: hover or selected card.
- Level 3: drawer, popover, command center.
- Level 4: modal.

## Icon Sizing

- Inline icons: 16 px.
- Button icons: 18-20 px.
- Module icons: 20-24 px.
- Hero supporting icons: 24 px maximum.

## Card Sizing

- Project card desktop minimum height: 160 px.
- Priority card minimum height: 96 px.
- Knowledge card minimum height: 112 px.
- Quick action minimum touch area: 44 by 44 px.

## Module Spacing

- Desktop module gap: 20-24 px.
- Tablet module gap: 18-20 px.
- Mobile module gap: 16 px.
