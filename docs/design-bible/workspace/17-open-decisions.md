# 17 - Open Decisions

| Decision | Context | Options | Recommended Direction | Owner | Status |
| --- | --- | --- | --- | --- | --- |
| Can employees reorder modules? | Workspace should feel personal but predictable | No, role default only, user reorder | Role default plus limited user reorder | Product/Design | Open |
| Can departments create custom modules? | Departments may have different work rhythms | No, admin templates, department modules | Admin-managed templates first | Product | Open |
| Should Workspace Memory expire? | Old resume suggestions can become stale | Never, fixed expiration, project-state expiration | Expire by project state and time | Product/Privacy | Recommended |
| Should My AI be dismissible? | Briefing can become noise | Always, only optional items, never | Optional items dismissible, required items actionable | Product | Recommended |
| Can modules be hidden? | Users may want focus | No, focus mode only, user hide | Focus mode plus limited hide | Design/Product | Open |
| Is Calendar required in v1? | Scheduling may depend on integrations | Required, optional, later | Optional integration module | Product/Engineering | Open |
| How many pinned projects? | Pinned work can dominate | 3, 5, unlimited | 3 visible, more in Projects | Design | Recommended |
| Should Emergency mode be automatic? | System risk may require attention | Manual, automatic, admin-triggered | Admin or system triggered for affected users | Product/Security | Open |
| Can Workspace show system status normally? | Status can distract employees | Always, only issues, admin only | Only relevant issues for employees | Design | Recommended |
| Can My AI mention private preferences? | Privacy and trust concern | Yes, no, only to owner | Only to owner, never to managers | Product/Privacy | Recommended |
