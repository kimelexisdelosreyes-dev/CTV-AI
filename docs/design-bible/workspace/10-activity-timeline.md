# 10 - Activity Timeline

## Purpose

The Activity Timeline complements notifications. It shows what changed in work context, grouped by meaning and time.

## Example Events

- AI completed subtitle generation.
- Archive indexed.
- Script updated.
- Project approved.
- Knowledge updated.
- File uploaded.
- Approval requested.
- Comment added.

## Grouping

- Today.
- Yesterday.
- Earlier this week.
- By project when several changes share context.

## Filtering

- All.
- My work.
- Projects.
- AI jobs.
- Knowledge.
- Approvals.
- Files.

## Timeline Item Anatomy

- Icon.
- Event sentence.
- Relative time.
- Source project or space.
- Actor when relevant.
- Action when useful.

```text
15 min ago  AI completed subtitle generation for Fire Documentary. [Review]
1 hour ago  Script v4 was updated by Mina Lee. [Open]
Yesterday   Archive photos were indexed for Old Manila segment. [View]
```

## Relationship To Notifications

Notifications ask for attention. Timeline preserves context. A critical notification may also appear as a timeline event, but routine timeline events do not need notification badges.
