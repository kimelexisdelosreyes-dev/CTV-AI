# 18 - Responsive Experience

## Desktop

- Persistent sidebar.
- Full command center.
- Multi-column Workspace.
- Right-side drawers.
- Dense admin tables.
- Full Permission Matrix.

## Tablet

- Collapsible sidebar.
- Reduced columns.
- Bottom sheets or full-screen drawers.
- Touch-friendly controls.
- Project context navigation becomes tabs.
- Tables reduce to key columns plus row expansion.

## Mobile

- Bottom or compact navigation.
- Priority-first Workspace.
- Full-screen search.
- Simplified project navigation.
- Limited administration.
- No dense Permission Matrix.
- Clear file preview limitations.
- Background AI job monitoring.
- Notifications optimized for action.

## Movement Rules

| Module | Desktop | Tablet | Mobile |
| --- | --- | --- | --- |
| Sidebar | Expanded/collapsed | Rail/collapsed | Menu sheet or bottom nav |
| Universal Search | Overlay | Overlay | Full-screen |
| AI Jobs | Right drawer | Drawer/sheet | Full-screen sheet |
| Notifications | Right drawer | Drawer/sheet | Full-screen sheet |
| Workspace modules | Multi-column | Two-column | Priority stack |
| Project navigation | Side or tabs | Tabs | Section picker |
| Permission Matrix | Full table | Reduced comparison | Desktop-required task |
| File preview | Side panel | Full panel | Limited preview |
