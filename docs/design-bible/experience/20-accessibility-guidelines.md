# 20 - Accessibility Guidelines

## Standard

Target WCAG 2.2 AA. Do not claim existing compliance until verified in implementation.

## Requirements

- Keyboard navigation for all controls.
- Logical focus order.
- Visible focus states.
- Screen reader labels for icon controls.
- Semantic landmarks: header, nav, main, aside where appropriate.
- Dialog focus trapping and focus restoration.
- Reduced motion support.
- Color contrast meeting AA.
- Non-color status indicators.
- Error announcements.
- Accessible data tables.
- Accessible Universal Search.
- Mobile touch targets at least 44 by 44 px.
- Zoom behavior without overlap.
- Text scaling without clipped controls.
- Accessible charts with text summaries.
- Accessible Permission Matrix with row, column, and cell state.
- Accessible AI progress states with meaningful announcements.
