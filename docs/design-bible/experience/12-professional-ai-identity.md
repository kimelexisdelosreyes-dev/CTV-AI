# 12 - Professional AI Identity

## Recommendation

Use **My AI** in employee-facing navigation. Use **Professional AI Identity** as the formal feature name on the page, in admin review, and in policy documentation.

## Definition

Professional AI Identity is an employee-controlled professional profile that helps CTV ONE adapt writing, communication, creative preferences, language, and workflow assistance.

It must not store sensitive HR data or become an HR evaluation tool.

## Sections

- Professional Summary
- Languages
- Expertise
- Role Context
- Communication Preferences
- Writing Style
- Creative Style
- Workflow Preferences
- Software and Tools
- Response Preferences
- Accessibility Preferences
- AI Guidance
- Profile Completion

## Explicit Exclusions

- Political beliefs
- Religious beliefs
- Medical information
- Private family information
- Psychological diagnosis
- Personal surveillance
- Performance evaluation
- Disciplinary information
- Compensation
- Private HR notes

## Ownership And Visibility

- Employee owns editing of personal professional preferences.
- Managers may see only business-safe fields required for collaboration.
- Admins may manage access and completion state, not private preference contents unless policy permits.
- Users can disable personalization where allowed.
- Project-specific context can override profile preferences for that project only.

## Lifecycle

First login -> Confirm professional details -> Choose optional preferences -> Review privacy explanation -> Save profile -> Use with permitted AI capabilities -> Edit, export, reset, or disable personalization.

## Conflict Handling

- Project brand rules override writing style.
- Accessibility preferences override visual defaults.
- Security policy overrides external communication preferences.
- User-disabled personalization overrides optional AI adaptation.
